## Почему ARG?

> **ИИ — ваш второй пилот, а не капитан.** ARG не пишет вашу статью. Он берёт на себя рутину — поиск литературы, форматирование цитат, проверку данных, контроль логической согласованности — чтобы вы сосредоточились на том, что действительно требует вашего мозга.

| Проблема | Решение ARG |
|----------|------------|
| Галлюцинации цитат | Верификация Semantic Scholar API + шлюзы целостности |
| Блокировка фрейма | Адвокат дьявола + протокол порога уступки |
| Подобострастие | Антиподобострастный скоринг (шкала 1-5 перед уступкой) |
| Преждевременная сходимость | Обнаружение намерения + мониторинг здоровья диалога |
| Фабрикация методологии | 7-модовый блокирующий чеклист на Stage 2.5 и 4.5 |

## Быстрый старт

```bash
git clone https://github.com/Masqiller/ARG-Researcher.git ~/ARG-Researcher
```

Откройте репозиторий в IDE. Конфигурационные файлы обнаруживаются автоматически:

| Агент | Конфигурация | Команды |
|:------|:------------|:--------|
| **Windsurf** | `.windsurf/workflows/arg-*.md` | Нативные `/arg-*` воркфлоу |
| **Cursor** | `.cursor/rules/arg-instructions.mdc` | `/arg-*` в чате |
| **Claude Code** | `.claude/CLAUDE.md` + `commands/` | Нативные `/arg-*` команды |
| **GitHub Copilot** | `.github/copilot-instructions.md` | `/arg-*` в чате |
| **Другие** | `.ai/instructions.md` | `/arg-*` в чате |

**Тест:** Выполните `/arg-plan` и опишите статью, над которой работаете.

## Команды `/arg-*`

| Команда | Описание |
|:--------|:---------|
| `/arg-full` | Полный конвейер: исследование → написание → рецензирование → правка → финализация |
| `/arg-plan` | Сократическое планирование по главам |
| `/arg-outline` | Подробный план + карта доказательств |
| `/arg-abstract` | Двуязычное резюме + ключевые слова |
| `/arg-revision` | Исправленная рукопись + ответы R&R |
| `/arg-lit-review` | Аннотированная библиография в формате статьи |
| `/arg-format-convert` | Конвертация в LaTeX / DOCX / PDF / Markdown |
| `/arg-citation-check` | Отчёт об ошибках цитирования |
| `/arg-disclosure` | Заявление об использовании ИИ |
